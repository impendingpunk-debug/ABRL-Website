# ABRL GitHub Pages Website

Upload the CONTENTS of this folder to the root of your `abrl` GitHub repository.

## Pages
- index.html — Home
- schedule.html — Season 1 schedule and race night
- standings.html — Championship standings
- results.html — Race results
- drivers.html — Driver profiles
- rules.html — League rules
- css/styles.css — Shared styling
- js/site.js — Shared mobile menu and placeholder-link behavior
- assets/abrl-flyer.jpg — League artwork

## GitHub Pages
Your repository should look like:

abrl/
  index.html
  schedule.html
  standings.html
  results.html
  drivers.html
  rules.html
  css/
    styles.css
  js/
    site.js
  assets/
    abrl-flyer.jpg

GitHub Pages will serve `index.html` as the homepage.
